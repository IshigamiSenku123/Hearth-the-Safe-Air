# V1 Backend Skeleton

This is the foundational backend structure for SafeAir. It provides:
- Firebase Realtime Database schema
- Cloud Functions skeleton for future secure API routing
- Data validation rules

**Status:** Send-only. This backend does not yet support bidirectional "Back-Functionality" (commanding the device).

**Future work:** Grow this into a secure middleman that hides Firebase credentials from the web app and handles authentication/App Check.
